# Site Van Service Atualizado

Arquivos prontos para subir no GitHub e publicar automaticamente no Vercel.

Atualizações incluídas:
- Botão flutuante do WhatsApp
- Botões "Fale Conosco" com clique direto para WhatsApp
- Logo Shuttle Aeroporto no topo do lado direito
- Site responsivo para computador e celular
- SEO local para São José do Rio Preto, Olímpia, Barretos, Guapiaçu e Mirassol

Configuração no Vercel:
- Framework: Vite
- Build command: npm run build
- Output directory: dist
